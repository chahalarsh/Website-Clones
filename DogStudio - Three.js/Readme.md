# Dog Studio Website Clone

A 3D website clone built while learning **Three.js** and modern web development.

### What I Learned

* Working with **Three.js**
* Loading and displaying 3D `.glb` / GLTF models
* Controlling 3D animations with scroll
* Setting up cameras, lighting, and scenes
* Creating smooth interactive web experiences

### Tech Stack

* JavaScript
* React.js
* Three.js
* Vite
* HTML & CSS
